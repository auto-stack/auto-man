# Auto-Man 文档

## 简介

Auto-Man 是一款为嵌入式系统开发设计的综合性包管理和构建系统工具。它通过提供项目模板、依赖管理、设备支持和自动化构建流程来简化开发工作流程。Auto-Man 使开发人员能够轻松地将 Auto 语言代码转译为 C 语言，使用不同的模板创建项目，并高效地管理依赖关系。

## 主要特性

### 项目模板

Auto-Man 提供了多种项目模板，以便快速启动新项目：

- **应用模板**：创建 Auto 语言应用程序项目
- **库模板**：创建 Auto 语言库项目
- **C 应用模板**：创建 C 语言应用程序项目
- **C 库模板**：创建 C 语言库项目

### 依赖管理

Auto-Man 简化了依赖处理：

- 自动依赖扫描和解析
- 递归依赖下载
- 集中式依赖仓库管理
- 依赖更新和版本跟踪

### Auto-to-C 转译

该工具具有复杂的转译系统，可以：

- 将 Auto 语言代码转换为 C 语言
- 生成适当的头文件和源文件
- 在优化目标平台的同时保持代码功能

### 设备支持

Auto-Man 包含全面的设备管理系统：

- 支持各种嵌入式设备
- 管理设备特定配置
- 提供对设备仓库的便捷访问
- 列出可用设备及其规格

### 项目类型支持

Auto-Man 支持开发不同类型的项目：

- **标准应用程序**：常规嵌入式应用程序
- **FreeRTOS 项目**：使用 FreeRTOS 实时操作系统的项目
- **混合项目**：结合不同语言或框架的项目

### 构建系统集成

该工具与构建系统集成，可以：

- 生成 CMake 配置文件
- 处理特定平台的构建设置
- 管理构建变体（调试/发布）
- 清理构建产物

## 使用示例

### 创建新项目

创建新的 Auto 语言应用程序：
```bash
automan app <project-name>
```

创建新的 C 语言应用程序：
```bash
automan capp <project-name>
```

创建新的 Auto 语言库：
```bash
automan lib <project-name>
```

创建新的 C 语言库：
```bash
automan clib <project-name>
```

### 管理依赖

列出所有可用依赖：
```bash
automan deps
```

更新项目依赖：
```bash
automan update
```

扫描当前项目的依赖：
```bash
automan scan [--port <port-name>]
```

### 设备管理

列出所有可用设备：
```bash
automan devices
```

### 构建和运行

构建当前项目：
```bash
automan build [--dir <directory>] [--port <port-name>]
```

运行已构建的应用程序：
```bash
automan run
```

清理项目（删除构建产物）：
```bash
automan clean [--dir <directory>]
```

## 项目结构

一个典型的 Auto-Man 项目包含：

- `pac.at`：项目配置文件
- 源文件（Auto 语言使用 `.at`，C 语言使用 `.c`/`.h`）
- `deps/`：下载的依赖目录
- `devices/`：设备配置目录
- `build/`：构建输出目录

## 配置

项目配置通过 `pac.at` 文件管理，该文件定义：

- 项目名称和元数据
- 依赖关系
- 目标平台
- 构建配置
- 端口配置

## 高级用法

### FreeRTOS 项目

Auto-Man 为基于 FreeRTOS 的项目提供专门支持，处理实时操作系统开发所需的特定要求和配置。

### 混合语言项目

对于结合 Auto 语言和 C 代码的项目，Auto-Man 无缝处理转译和集成，允许开发人员利用两种语言的优势。

### 自定义端口选择

当有多个端口可用时，Auto-Man 提供交互式选择过程：

```bash
automan build
# 如果有多个端口可用，会提示选择端口
```

## 故障排除

如果您遇到问题：

1. 确保您的 `pac.at` 文件配置正确
2. 尝试使用 `automan clean` 清理项目
3. 检查依赖版本和兼容性
4. 验证目标硬件的设备支持
